    Reading the experiment+

    Conventions need a purpose. The reference game gives each agent different information and a shared success signal. Repeated rounds and a smaller message budget create pressure to communicate efficiently. Open conversation is useful for exploration, with less objective evidence of successful communication.

    English stays the working language. Agents may negotiate compact English phrases and agreed meanings. Their model weights remain fixed: any adaptation occurs within the conversation context. The word cap is enforced, so an overlong message can be clipped.

    Observe, then investigate. Accuracy, length, and lexical diversity describe the exchange; none proves a new language has emerged. Export runs to inspect exact prompts, compare seeds and settings, and check whether conventions survive new examples. Private task information is visible in exported research records.
